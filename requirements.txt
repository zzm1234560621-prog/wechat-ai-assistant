# --- wcferry：**只有走 wcferry 后端（微信 3.9.x）才需要** ---------------------
# 项目主线是 **微信 4.x + aixed hook**（version.dll 注入，本地 HTTP :30001），
# 主线不需要 wcferry。装不上 wcferry **不影响主线**：
#   * installer 会明确报出「wcferry 没装上」，然后照常把其余依赖装完（不是静默失败）；
#   * 真要 wcferry 后端时，先把微信降到下表版本再装对应的 wcferry。
#
# 版本对应表（与 wechat_version.py 的 WX_TO_WCFER 保持一致，改一处要改两处）：
#   微信 3.9.12.51  -> wcferry==39.5.2
#   微信 3.9.12.17  -> wcferry==39.4.4
#   微信 3.9.11.25  -> wcferry==39.3.0
#   微信 3.9.10.27  -> wcferry==39.2.0
#   微信 3.9.10.19  -> wcferry==39.1.0
#
# 这里刻意**不写上界**：wcferry 的版本必须跟着微信版本走，写死一个版本会让
# 「微信 3.9.12.51 + 39.5.2」这类组合反而装不上。真正生效的版本由 installer.py
# 按检测结果覆盖（envsetup.set_version），手动安装时请照上面的表自己填 ==版本。
#
# ⚠️ 版本号写法：上面表里的 `39.5.2` / `39.4.4` 是「文档里的三位写法」，PyPI 上实际发布的
#    是四位版本（39.5.2.0 / 39.4.5.0 ……）。PEP 440 比较时 39.5.2 < 39.5.2.0，
#    所以这里写 `>=39.4.4` 会解析到 **39.4.5.0**，能装上但不是我们要的那个版本——
#    真要 wcferry 后端时，请用 installer.py 装（它会按微信版本覆盖成精确版本），
#    或自己 `pip install wcferry==39.5.2.0`。
wcferry>=39.4.4
